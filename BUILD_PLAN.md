## Decisions (confirmed with the user, 08-Oct-2026)
- **One data universe** for all 5 towers: the manifests in `fct details/` (`FCT_Financial_Controller_Technical_Manifest.md` = cross-tower, `5_Supply_Chain.md` = SC). Persona **Priya Raman**, Group Financial Controller; client Jubilant (demo); period **Sep-26 (Q2 FY27)**; demo clock **Mon 05-Oct-2026 09:10 IST**, close day WD+2, target WD+4; 10 entities IN-01…IN-08, US-01, EU-01. The R2R/O2C/P2P/CMP drill-down docs define *screens, features, KPIs, scenarios*; their example numbers are re-expressed in this universe (e.g. R2R doc "JV-55102 ₹3.9 Cr" → manifest RTR-JNL-02 ₹2.40 Cr; "Meera Rao" → Priya Raman).
- **Structure:** Login → Persona select → Controller Home (cross-tower desk, queue, decision log) + 5 tower modules with every screen from each tower doc. Shared decision drawer everywhere.
- **Hosting:** Railway **config only** (`railway.json`, `server.js`, `package.json`); the user deploys. Do not run `railway up`.
- **Login:** `admin` / `FCT@towers#2026` (baked into `assets/js/fct-core.js`, `FCT.AUTH`).

## Tech rules
- Static HTML/CSS/vanilla JS, classic `<script>` tags, no build, no backend, works from `file://` and from `server.js`.
- Data lives in `data/*.js` as `window.FCT_DATA.<section> = {...}` (JS, not JSON, so file:// works). Load order: `data/core.js` → `data/exceptions.js` → tower files.
- State: `localStorage['fct-demo-v1']` via `FCT.state`. Decisions apply **effects** (`set` / `delta` on metric keys) read through `FCT.v(key, base)`. "Reset demo" in the user menu restores the seed.
- Chart.js 4.4.1 (cdnjs). Fonts: Newsreader (titles), IBM Plex Sans (UI) from Google Fonts.
- Every page: `<body data-page="<tower>/<screen>" data-root="../../">`, includes `assets/css/fct.css`, data files, `assets/js/fct-core.js`, `assets/js/fct-ui.js`, then an inline page script that calls `FCT.page({...})`.

## How to add a screen (pattern)
1. Data in `data/<tower>.js` (`D.<tower>` object, `D.metrics` keys, extra exceptions via `D.exceptions.push`).
2. Page = copy any built page in the same tower; `FCT.page({render(el){ ... }})` with `FCT.ui.head/band/panel/table/queue/aiCard/chart/modal/act`.
3. Exceptions open in the shared drawer via `data-x="ID"`; non-exception workflows record with `FCT.ui.act(id, rec, effects, toast)`, page-local state in `FCT.state.notes.<key>`.
4. Holding pages for unbuilt screens come from `python3 tools/stub.py` (never overwrites).
5. QA: `node server.js` (PORT=8765) and check console errors in each page; screenshot via playwright-core (scratchpad `check.js`).
